# VariantScope：桌面原生层级视觉重设计

验收日期：2026-11-25（Asia/Shanghai）。基于 `8542c8d` 的真实界面重新组织前端结构。Java 后端、MySQL 数据表、VCF 解析、查询接口和统计口径均未更改；所有图表来自原服务返回的数据。

## 设计依据与取舍

参考 Apple 官方 [Designing for macOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-macos)、[Charts](https://developer.apple.com/design/human-interface-guidelines/charts)、[Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)。采用其清晰层级、桌面信息密度、可收起导航与按数据意义选择图形的原则；具体布局、颜色、标识和组件均为 VariantScope 自己实现。没有复制 Apple 应用界面、品牌标识、交通灯控件或字体文件。这是运行在浏览器中的专业工具界面，不声称变成原生 macOS 应用。

| 设计决策 | 改造前 | 本次实现 |
|---|---|---|
| 工作空间 | 白色主内容与浅侧栏平铺 | 外层中性背景、统一桌面容器、工具栏、分组内容页形成三层表面 |
| 导航 | 始终展开，主要靠页面切换 | 桌面 218px 资料库，可收为 68px 图标导航；窄屏由工具栏展开并在选择后收起 |
| 工具栏 | 面包屑、技术标签、重复页面信息 | 删除面包屑与技术装饰，保留侧栏开关、当前页面、检索、刷新及导入真实操作 |
| 字体 | 打包 Inter Variable | `-apple-system, BlinkMacSystemFont, Helvetica Neue, PingFang SC, Microsoft YaHei, sans-serif`；不分发 SF 或其他 Apple 字体 |
| 排版 | 页面标题 26px，主要指标 41px | 页面标题 23px/500，指标 28px 与 24px；表格为等宽数字，次级文字提高可读对比 |
| 色彩与表面 | 白色图表大网格，绿色强调 | #587da4 克制强调色，#e9edf3 导航、#f3f4f7 内容，低对比边线，6/11/14px 圆角 |
| 概览结构 | 上下平铺的数据集、指标、同构图表 | 文件与统计合为摘要面板；单分组摘要、构成分析及宽幅替换图按信息性质组织 |
| 单 Contig | 一根高柱与空旷坐标轴 | 紧凑的类别、数量、横向记录带和明确说明；不推断其他染色体或参考序列长度 |
| 类型极不均衡 | 小类别横条很难点选 | 真实线性构成带 + 全类别精确数量/百分比 + 主类型摘要；小类别不人为放大 |
| 表格 | 普通行与详情弹窗 | 更紧凑的交替行、固定表头、持续选中反馈、折叠筛选检查器、浮动详情面板 |
| 状态反馈 | 全局加载文字 | 加载骨架、真实传输/解析分阶段进度、原生确认弹窗与轻微反馈；尊重减少动态效果设置 |

系统字体随平台实际可用字体回退。在 Mac 上优先使用系统 UI 字体和 PingFang SC；不通过下载、转换或捆绑 Apple 专有字体实现。Inter 依赖与分发文件已经移除。

## 所有页面的实际修改

- **概览**：文件、样本、参考版本、总数与统计口径集中在一张组合面板；不再让大数字压过文件上下文。真实只有 1 个 Contig 时显示简洁的摘要，不画虚假的全基因组分布。
- **数据集管理**：导入文件区域、可选元数据、提交和公开示例形成独立分组；上传百分比与解析等待阶段分别展示，未把传输 100% 当成解析完成。
- **变异浏览**：保持后端分页和组合条件；筛选可收起，已应用条件仍可见；数字右对齐、REF/ALT 保留、表头固定、约 39.5px 行高；详情关闭后仍有选中行提示。
- **统计分析**：六类图表统一系统字体、少量网格线、悬停、配色与数值入口；单分组数据自动使用紧凑表达。图形比例及 Ti/Tv 计算均未改动。
- **项目说明**：使用分组文档页展示来源、指标方法和支持边界，降低标题字重与尺寸，手机转为单列。

保留原 API 请求、查询草稿/已应用范围、CSV、PNG、原生 dialog 焦点管理及已拆分组件。新增 `LoadingSkeleton`，调整 `Chart` 的数据自适应表达；没有引入庞大的新组件库或重写后端。

五页均检查 1440px 与 390px：桌面 scrollWidth=1440，手机 scrollWidth=390，无页面级横向溢出。科学表格在自己的容器内横向滚动；手机实际行高约 39.5px。桌面导航收合后当前数据集与筛选范围不变；窄屏导航的 aria-expanded 与实际显示状态一致。

真实交互结果：

1. 系统字体栈从实际 computed style 核对；运行时不请求打包字体文件。
2. 点击类型构成带的 SNV 联动到 922 条结果；CSV 真实下载并数得 922 行。
3. 打开 1:69134，原始 INFO、缺失 GT 显示正常；Escape 关闭后焦点回到原坐标按钮，保留 1 条选中行。

## 已知限制

- 本次浏览器检查基于 Chromium 的桌面与窄屏视口，不声称已在真实 iOS Safari、Android 或全部辅助技术上完成认证。
- PNG 仍为图形区域导出；类型图包含逐类数值，但页面级来源说明不自动写入 PNG，未增加 SVG。
- 系统字体的具体字形与抗锯齿由运行平台决定；非 macOS 不会获得 Apple 专有字体文件。
- 单 Contig 的横向记录带表示当前分组记录数，不表示染色体长度、测序覆盖率或样本质量。
- Java/MySQL 的现有分析边界与百万级统计性能限制不变；本次没有重跑后端性能压测，不将旧结果冒充新测试。
