# VariantScope UI/UX 重构与验收

验收日期：2026-11-25（Asia/Shanghai）。前端在现有 VariantScope 仓库内改造，后端目录没有修改。现有 MySQL 数据、API、VCF 解析与统计口径继续使用。

## 页面与信息架构

- **概览工作台**：当前数据集、参考基因组、样本与导入时间置于上下文栏；以一项主指标和三项辅助指标替代同构 KPI 卡片；分布区使用统一的双列分析网格，最近导入为紧凑列表。
- **数据集管理**：上传区域明确区分文件选择、可选元数据、进度和提交；可选择或拖入 VCF；右侧说明真实公开示例来源；数据目录统一状态、数值对齐和管理操作。删除使用带焦点管理的原生 dialog。
- **变异浏览**：筛选草稿与已应用条件分离，明确展示实际查询范围；REF、ALT 独立列，数值使用等宽数字并右对齐，长序列省略但保留 title 与完整详情；固定 FILTER 列宽，表头粘性、表内滚动。详情抽屉区分 VCF 来源与系统计算，展示 GT、INFO 和原始行。
- **统计分析**：复用同一上下文、筛选与指标组件；六类图表共享字体、色板、坐标网格、悬停和导出规则。拥挤饼图改为横向条形图，依次呈现 SNV、插入、缺失、复杂替换、未分类，显示数量与占比。
- **项目说明**：用两栏文档布局说明来源、统计口径和适用边界；手机转单列。
- 原项目没有独立路由库，本次保留轻量导航方式并增加稳定的 `#overview/#datasets/#variants/#analysis/#about` 页面定位，支持刷新定位与浏览器历史，不引入额外路由框架。

## Design System

| 项目 | 规范 |
|---|---|
| 字体 | 本地打包 Inter Variable + PingFang SC / Source Han Sans SC；不依赖运行时字体 CDN |
| 字重 | 正文 400，辅助数据 450，标题 500–550；减少中文粗体 |
| 数字 | tabular-nums；坐标与等位序列使用 SFMono/Consolas 等宽字体 |
| 字号 | 页面标题 26px（移动端 23px）；分区标题 14–16px；输入与主操作 14px；表格数据 13px；次级说明 11–12px |
| 间距 | 4/8/12/16/20/24/32/40px 变量；内容按分析分区组织 |
| 主色 | #287c6d，生物信息学绿色；文本 #242e33，次级文本 #636e75 |
| 表面与边框 | 白色内容、#f6f8f7 导航、#e6e9e9 细分隔；不使用渐变、玻璃或厚重投影 |
| 圆角 | 5/8/10px；仅弹窗和浮层使用轻量阴影 |
| 导航 | 204px 浅色侧栏，紧凑线性图标、低饱和选中底色；手机为横向滚动导航 |
| 图表颜色 | SNV 绿色、插入蓝色、缺失土金色、复杂替换紫色、未分类灰色；碱基替换区分转换与颠换 |
| 动效 | 短暂加载与图表过渡，尊重 prefers-reduced-motion 的界面动画设置 |

图表复用原 ECharts 模块的渲染、ResizeObserver、PNG 导出及点击事件机制，改造排版和主题；没有使用外部产品的品牌组件或图表截图。辅助读取了用户允许的计算机视觉平台 main.css/trends.css，仅参考紧凑的信息组织，没有复制其配色、资产或业务代码。Inter 字体附带 SIL OFL 1.1 许可。

## 组件复用与拆分

`Chart.vue`、原有 API 调用与请求路径继续复用。抽出 `DatasetContext`、`MetricSummary`、`FilterBar`、`VariantTable`、`VariantDetail`、`StatusBadge`、`UiDialog`、`UiIcon` 和 `DatasetManager`，五页共用设计变量与控件。`lib/domain.ts` 提供有类型的数据结构、查询序列化及来源字段显示语义。

此次同时修复：

1. 未提交的筛选直接改变导出链接，导致范围可能与表格不一致。
2. 数据集切换时筛选条件残留；请求失败保留旧记录；取消选择时较晚返回的请求覆盖新状态。
3. 非 JSON 上传错误响应未妥善反馈；无效文件替换后仍残留上一个可提交文件。
4. 移动端 FILTER 列挤压导致行高不必要膨胀；修复后实测行高 45px。
5. 翻页/排序无须重复计算全量统计；统计保持原查询范围，列表单独请求。

## 实际验证

- `npm run test`：3 个文件、**12 项测试全部通过**。覆盖未应用草稿隔离、导出范围一致、数据集切换、零值/缺失值、GT/INFO 语义、文件校验、上传载荷、错误清理、迟到响应与安全重试。
- `npm run build`：严格 TypeScript 检查与 Vite 生产构建通过，无大包警告。
- `npm audit`：**0 项漏洞**。测试工具相关 glob/minimatch 使用修复版本并经测试；生产 ECharts 升级到 6.1.0，已重新验证实际导出和点击交互。
- 原 `scripts/smoke.py` 在真实 MySQL 8 服务上执行通过，涵盖导入、组合查询、分页、统计、CSV 转义、重新分析、重复拒绝、异常和删除。
- GitHub Actions 的代码提交 `8359379` 已通过，包含后端原有 11 项测试与新增前端 12 项测试、前端构建。

## 加载优化

原重构构建中单入口约 641 KB。最终主入口 **112.11 KB / gzip 43.57 KB**，Chart 组件 4.63 KB，图表模块 352.57 KB，渲染引擎 176.61 KB。图表按需加载并独立缓存，数据集页不强制加载图表。这里只报告产物大小和实际分包加载；没有把分包解释为总体 JS 同比例减少，也没有虚构首屏时间指标。

## 保留的限制

- 手机复杂科学表格仍需在表格内部横向滚动；不把九列压成难读的卡片。
- PNG 导出继续导出图形区域，图表标题与来源说明仍在界面展示；未新增 SVG 导出。
- 浏览器检查基于本机 Chromium 的桌面与手机视口模拟，没有声称覆盖真实 iOS Safari/Android 设备或全套无障碍审计。
- 原后端的单样本、100 MB/100 万行、多等位/结构变异标记、无临床推断等边界均保留；没有新增统计缓存或改变数据库。
- 字体许可及依赖已随源码记录。原项目 V1.0 的历史性能报告仍保留，不能将其解释为本次重新执行的后端性能测试。
